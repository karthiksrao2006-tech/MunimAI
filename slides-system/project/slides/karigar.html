Component 6 · batch · the new idea

Karigar: the agent that builds agents

Karigar (literally "craftsman") is a meta-agent. When the system meets a task none of the six specialists cover, it doesn't fail — it drafts a new one.

1 · gap found

Example: a new state rolls out a different e-way bill rule the Compliance agent doesn't handle.

2 · draft

Karigar writes a SKILL.md, its tool bindings, and a small synthetic eval set — on the supercomputer, not live.

3 · self-test

Runs the new agent against the eval set. Below a pass threshold, it is discarded, not shipped.

4 · promote

Only a passing agent is registered with the orchestrator and reaches the live path.

The safety gate is the point: Karigar can propose, it cannot deploy. Step 3 is non-negotiable before anything it writes touches a real owner's business.

This is the "agent that creates other agents for problem-solving and coding" the team asked for, done with a hard gate so it stays safe on a product that touches real money and compliance.
