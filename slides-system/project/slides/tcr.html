Component 1 · live

The Tiered Cognition Router

Not every message needs a big brain. The router decides, in milliseconds, whether a small local model can answer or the turn needs to escalate.

~85% of turns

Tier 1 · local 7B

Classify a bill, extract a number, pick an intent, draft a routine reply. Qwen2.5-7B-AWQ, on the cloud runtime, answers in under 2 seconds.

~15% of turns

Tier 2 · escalation

A novel eligibility edge case, an ambiguous notice, a low-confidence OCR read. Goes to a larger model (hosted API or next batch run), with the owner told it will take longer.

Why it matters: cost and latency collapse because the expensive model is only called when it changes the decision — not on every turn. This is what keeps the live server inside 15GB VRAM.

This is one of our original contributions, not a standard pattern. The 85/15 split is a design target we'll tune against real traffic once we have usage data.
