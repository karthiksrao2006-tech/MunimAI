The verifier gate: nothing ships unchecked

Every single agent output is checked against four rules before the owner ever sees it. Fail any one, and the output is held, with a reason, not silently fixed.

Rule 1

Citation required

A scheme eligibility claim with no retrieved clause attached is rejected outright. No citation, no claim.

Rule 2

Rule version current

Every answer carries the CBIC/scheme notification date it used. Stale version → re-run against the current rulebook.

Rule 3

Consent active

Any tool call touching bank/AA data checks for a live, purpose-bound consent token first.

Rule 4

Prepare, never file

GST filing and loan submission stay simulated. The gate blocks any action that would actually submit on the owner's behalf.

This slide answers the hardest judge question directly: how do you keep an LLM from hallucinating a scheme eligibility rule. Answer: it's structurally impossible to show an uncited answer, not just prompted against.
